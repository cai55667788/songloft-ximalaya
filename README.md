# 喜马拉雅 for Songloft

把喜马拉雅的有声书、评书、音乐导入 Songloft，并带一个为「听书」设计的播放器。

> 非官方插件，与喜马拉雅官方无关。内容版权归喜马拉雅及原作者所有，请仅用于个人收听。

## 功能

**找**

- 关键词搜索专辑（联想词扩展聚合，绕开搜索接口的风控）
- 单集（声音）搜索：直接搜某一集，单集试听或一键收藏进歌单
- 手机扫码登录（设置页 → 生成二维码 → 喜马拉雅 App 扫一扫），也可手动粘贴 Cookie
- 登录后读取「我订阅的专辑」，支持多选批量导入 / 只订阅不导入

**听**

- 专辑详情页：封面、作者、简介、分集列表分页；显示更新日期与发布日期（超过一年没更新会标红），付费/VIP 专辑有醒目的红色标识，连载中 / 已完结一目了然
- 断点续播：每 5 秒记进度，再打开自动跳回上次位置
- 跨页自动连播：播完一集自动下一集，本页听完自动接入下一页，长书可以一直听下去
- 最近收听：一个页面汇总所有听过的专辑，显示听到第几集、还剩多久，一键继续
- 倍速 0.75× ~ 2×
- 睡眠定时 15 / 30 / 45 / 60 / 90 分钟，或「本集播完」停止
- 已听标记：`⏱ 3:20` 未听完、`✓` 已听完，支持「只看未听」
- 正序 / 倒序：详情页与播放条都能一键切换，倒序时从最新一集开始听，追更类节目更顺手
- 播放队列面板：底部抽屉看整条队列，点行跳播、单集移出、一键清空、移除已听完的
- 章节书签：在任意时间点打点（可写备注），按天分组列出、点时间直接跳过去，存 NAS 跨设备可用
- A-B 复读：点两下框出一段反复听，越过终点自动回到起点，显示循环次数
- 播放历史时间线：按天列出听了哪一集、听到第几分钟、什么时间听的，点一条就从那儿继续
- 全屏播放页：大封面、大字标题、可拖动进度条、±15/30 秒、倍速、书签、复读在一块
- 快捷键：空格播放/暂停，← → 前后 10 秒，B 打书签，A 复读，Esc 逐层收起

**AI 智能整理**（可选，设置页填任意 OpenAI 格式网关即可）

- AI 速览：自动生成这本书的摘要、内容标签、「适合谁听」，并把长书按主题分成若干段
- 问这本书：直接用自然语言提问，只依据简介与分集标题作答，资料不足会直说
- 书签 AI 归类：把零散书签自动分成 干货 / 情节 / 笑点 / 疑问 / 待复查
- 主题分段可点：AI 切出的「第 21–60 集 进阶」点一下直接翻到那一集
- 分集一句话简介：给每集补一行「这集讲什么」，列表里直接可见
- 精彩片段推荐：AI 挑出最值得先听的几集并说明理由，点一下直接播
- 听书周报点评：周报除了数据，再来一段像人写的回顾
- 主模型不可用时自动降级到备用模型，不会因为网关抽风整个 AI 功能挂掉
- 结果按专辑缓存在 NAS，可重新生成、可一键清空

**控制与统计**

- 一句话让音箱播：输入「播郭德纲第 5 集」「继续听三体」「暂停」「声音大点」「我听到哪了」，直接在小米音箱上执行（本地解析，不依赖 AI）
- 听书习惯仪表盘：连续收听天数、24 小时时段热力图、听完率排行、剩余时长预估
- 收听报告：自动累计每本书／每天的收听时长，生成本周／本月／累计报告，可让音箱念出来
- 关键词自动追更：加一个关键词，每天自动搜新专辑、建歌单、只导最近 N 集

**同步与离线**

- 跨设备收听进度：进度存到 NAS，手机/平板/电脑共用一份，换设备接着听
- 本机音乐库联通：详情页标出「已下载 N 集」，分集打「本地」标，缺的集可一键补齐；播放时优先用本地文件
- 每天定时语音播报：有新集就用小爱音箱念出来（提示更新了哪张专辑、几集），播完可选自动续播最近在听的那本
- 整本下载到本地音乐目录：默认转 mp3、写入标签，按「子目录/主播/专辑/集名」分目录，断网也能听

**导入与订阅**

- 按区间导入（例如第 1–50 集）
- 多专辑合并成一个歌单，或每张单独建歌单
- 订阅后只增量拉取新集，追加到原歌单
- 每天定时自动同步，可选推送到智能音箱（需配合「智能音箱」插件）

**搜索与整理**

- 搜索历史（点一下再搜、右键删除、一键清空）
- 专辑对比：两张专辑比集数、播放量、订阅数、更新时间、付费情况，优的一侧高亮
- 按主播追更：订阅与导入的专辑按主播聚合，勾选批量订阅
- 导出订阅清单：JSON / CSV / Markdown（CSV 带 BOM，Excel 打开不乱码）
- 已听 / 未听一键拆成两个歌单

**运维**

- 运行日志面板（最近 100 条，可按等级筛）
- 插件自检（10 项体检，深度模式会真的取一次播放地址）
- Cookie 过期每日巡检，失效时设置页直接提示并可重新扫码

## 安装

**从插件商店**：Songloft 客户端 → 插件商店 → 选源菜单 → GitHub 发现 → 搜索「喜马拉雅」。

**手动安装**：下载 Release 里的 `ximalaya.jsplugin.zip`，在 Songloft → 设置 → 插件管理 上传。

要求宿主版本 ≥ 2.6.0。

## 使用

1. 打开插件 → 「设置」页 → 点「生成二维码」→ 手机喜马拉雅 App「扫一扫」并确认
2. 「搜索」页输入关键词找专辑，点标题进详情，可以先试听
3. 想长期跟进某张专辑，点「订阅」；之后同步时只拉新增的集数
4. 「订阅」页可设置每天自动同步时间，以及每天的语音播报时间与音箱（播完可自动续播最近在听的那本）
5. 「已导入」页点某张专辑的「下载」，可把整本存进 Songloft 本地音乐目录；之后详情页会标出「已下载 N 集」，差的可一键补下
6. 想用 AI 速览/提问/书签归类/分集简介/精彩片段，到「设置」页填网关地址、key 与模型名，点「测试」通了即可
7. 播放条上的「⏩ 跳片头」「🔂 单集」点一下即可开关；音量滑到合适后会被记住
8. 遇到问题先去「设置」页看「🩺 自检」和「📝 运行日志」——哪一项红了、最近发生了什么，那里写得最清楚

## 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 保存登录凭据、订阅列表、跨设备播放进度、播报与下载配置 |
| `songs.read` | 检查已导入的歌曲，避免重复导入 |
| `songs.write` | 导入单集时创建歌曲条目；下载到本地时改写歌曲为本地文件 |
| `playlists.read` | 读取已有歌单，用于增量追加与查重 |
| `playlists.write` | 创建歌单、追加新集 |
| `inter-plugin` | 与其他插件（如智能音箱）配合播放 |

运行日志只记录警告与错误，最多 100 条，存于插件自己的存储中，不会上传。

插件不读取音乐目录以外的文件，不向任何第三方上传数据；登录凭据只存在本机插件的存储里。

**关于 AI 功能**：AI 速览/提问/书签归类是**可选**的，默认关闭。只有你在设置页主动填入网关地址与 key 后才会调用，请求发往你填的地址（可以是本机网关、局域网模型服务或任意外部 OpenAI 兼容接口），发出去的内容只有专辑简介与分集标题（周报点评会发当天汇总的收听时长与书名列，不含具体时间点与设备信息），不包括登录凭据、Cookie。
